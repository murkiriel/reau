Three short videos complement the guide. Each page has the narration in its own language (Brazilian Portuguese, English or Spanish); the subtitles in your language are on by default, and the other two are in the player’s CC button.

Which APK to download

On the Releases page, download the file REau-0.4.0.apk. The 0.4.0 is the version and changes with each Release. Ignore the “Source code” items (zip and tar.gz): they are the source code and cannot be installed. They are the exact source code of the APK in the same Release (the tag of that version in the repository), as the AGPL-3.0 license asks; the same code is in the repository.

Checking the APK (optional)

Every APK carries the signature of whoever built it, and the fingerprint (SHA-256) of its certificate says which key that was. The APKs of the project’s Releases are signed with the project’s key, whose fingerprint is:

63f5c3ba687699b0b4288a878bd8372bed2c9632222d7f673ea71073aa208970

On a computer, apksigner verify --print-certs REau-0.4.0.apk (from the Android SDK build-tools) prints the line certificate SHA-256 digest of the file you downloaded: compare it with the value above. If they differ, the file was not signed with the project’s key; do not install it as if it were a Release.

The Release also carries a SHA256SUMS file. With it and the APK in the same folder, sha256sum -c SHA256SUMS checks the file you downloaded; on Windows, certutil -hashfile REau-0.4.0.apk SHA256 prints the hash to compare with the value in SHA256SUMS.

Getting new versions through Obtainium (tip). Obtainium is a free third-party app that installs and updates apps straight from GitHub Releases, without a store. Install Obtainium, tap Add app, paste the address of the REau repository (https://github.com/Murkiriel/reau) and confirm. It tells you when a new version is out and installs it over the old one, keeping your settings. Only versions published in Releases count: test builds (such as 0.3.0-dev+…) are not Releases, and the option to include pre-releases should stay off. REau changes nothing because of this: its own check for updates (the Check now button and the daily notice) only tells you about a new version and opens its page, and never installs anything. Obtainium is a third-party app, which the project neither maintains nor guarantees.

Coming from the old REau Lite? REau 0.3.0 is a new app for you (the Lite had the package com.reau.app.lite): redo the settings and the pairing with the dash (the app starts empty: accept the terms again), then uninstall the old Lite. Coming from the earlier REau (com.reau.app)? Just install over it: settings and pairing stay. The accessibility service that earlier versions used is gone for good (it no longer shows in Android’s Accessibility settings), and Android Auto’s head unit server is now turned on by hand (see the guide). Two installations together compete for Android Auto’s single server.

The path in short

  1. Install the APK (REau-0.4.0.apk) from the Releases page; updates from the official app install over the old one and keep the settings; a test (debug) build and the official one cannot replace each other, so uninstall first, after sharing the logs from the app (Settings → Debug → Share), because uninstalling erases the app’s data.
  2. Open REau, accept the terms and allow location (only to find the dash’s Wi-Fi) and the suggested Wi-Fi networks.
  3. Turn on Android Auto developer mode (about 10 taps on Version) and start the head unit server by hand.
  4. Turn the bike on, tap Turn on and, the first time, Connect. With Android Auto Active and the dash Ready, it is streaming.
